## À propos

Je suis étudiante en classe préparatoire au cycle ingénieur informatique au CESI (campus de Nancy). Avant cela, j'ai suivi un bachelor en développement web full stack (3iL Ingénieurs, Université de Limoges) et un DEC en développement et applications mobiles (CCNB, Canada).

J'ai réalisé des projets web et mobile en contexte académique et professionnel : API REST avec Django et Node.js, interfaces React, application mobile Flutter. Aujourd'hui, je renforce mes bases en développement logiciel, en qualité du code, en conteneurisation et en intégration continue, avec l'objectif de devenir ingénieure cloud.

**Je recherche un stage en développement logiciel à partir du 10 mai 2027.**

## Projets

### CliniqueStock : gestion de stocks de médicaments

Application web full stack de gestion des stocks de médicaments.

- **Technologies** : Django REST Framework, React, TypeScript, PostgreSQL, Docker
- **Fonctionnalités** : suivi des mouvements de stock selon la méthode FIFO, alertes de stock et de péremption, génération de documents PDF, conteneurisation

### SGEE : système de gestion d'enrôlement des étudiants

Projet fil rouge. Application web visant à automatiser et sécuriser le processus d'inscription académique, de la collecte des informations à la production des documents officiels.

- **Technologies** : Django REST Framework, React

### BelgoLink : application mobile de mentorat agricole

Projet réalisé dans le cadre d'un stage.

- **Technologies** : Flutter, Node.js, MongoDB Atlas, API Google Gemini, Figma
- **Fonctionnalités** : authentification, CRUD, API REST, espace communautaire, mise en relation éleveurs et mentors, messagerie, chatbot conversationnel
